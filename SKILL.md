# Academic Phrasebank (Manchester)

## Overview

This skill packages the University of Manchester Academic Phrasebank into a local reference library: ready-made, content-neutral English phrases for every major section and communicative function of academic writing. Use it to draft, repair, or enrich sentences in a research paper, dissertation, thesis, essay, or report.

The phrases are generic templates, not copyrighted prose: replace the placeholders (`X`, `Y`) and the trailing ellipsis (`…`) with the writer's own content, and adapt tense and person to the text.

## When to Use

- User asks to draft or improve any academic English section: introduction, literature review, methods, results, discussion, conclusion.
- User needs hedged/cautious wording, critical commentary, definitions, classifications, comparisons, trend/quantity descriptions, causal claims, examples, transitions, or past-tense narration.
- User is a non-native English speaker and needs natural, register-appropriate academic phrasing.
- User explicitly mentions Phrasebank, academic phrases, or sentence templates.

Do not use for generating experimental data, statistics, or non-academic writing.

## Workflow

1. **Identify the function.** Determine the section or communicative function of the sentence(s) the user wants.
2. **Load the matching reference file(s).** Read the full file before drafting. For cross-cutting tasks (e.g., a discussion that hedges and compares), load all relevant files.
3. **Select 2–3 candidate phrasings.** Choose templates that fit the rhetorical move (e.g., "Identifying a knowledge gap" for a gap sentence).
4. **Adapt, do not copy verbatim.** Fill in `X`/`Y` with the user's subject matter, replace `…` with concrete content, and adjust tense/person:
   - Methods, results, past events → past tense.
   - Definitions, established facts, general claims → present tense.
   - Hedging (cautious language) for claims that are not established fact.
5. **Draft coherent prose.** Produce complete sentences or paragraphs, not template fragments, unless the user only asked for phrase suggestions.

## Usage Rules

- Replace all placeholders and ellipses; never return a phrase with `X`, `Y`, or `…` unresolved.
- Keep the register formal and impersonal unless first person is conventional in the target discipline (essays often use "I"; methods/results typically do not).
- Match hedging strength to certainty: strong evidence → confident verbs; limited evidence → cautious modifiers.
- Do not mix British and American spelling within one text.
- Preserve discipline-specific terminology from the user's own material.
- If the user writes in Chinese, produce English academic sentences and give a brief Chinese explanation of choices when useful.

## Common Mistakes

- Copying an example that contains content words ("antibacterial agents", "climate system") — always substitute the user's own domain.
- Using present tense in methods/results sections — those normally use simple past.
- Over-hedging strong findings or over-claiming weak ones.
- Writing fragment templates instead of complete sentences.
